# Linux Command Sheet — Cybersecurity Reference

A categorized Linux command reference with plain-English explanations for students, system administrators, and cybersecurity learners.

The goal is simple: make it easier to find the right command category without having to search through one long alphabetical list.

## How to use this reference

1. Find the category that matches the task.
2. Read the command explanation before running it.
3. Check the command's local manual page with `man command` or its help option.
4. Understand the effect of commands that modify files, permissions, services, or network settings.
5. Test unfamiliar commands in a safe lab or non-production environment.

## Responsible use

Some listed utilities can affect remote systems or access protected data. Documentation is for learning and authorized administration only. Use tools only on systems you own or are explicitly permitted to test, and follow applicable laws and organizational policies.
