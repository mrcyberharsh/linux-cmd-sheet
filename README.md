
# Linux Command Sheet — For Cybersecurity Professionals

A structured, categorised reference of Linux commands with plain-English explanations, built for security practitioners, students, and anyone working daily on the Linux CLI.

Unlike a flat alphabetical cheat sheet, commands here are grouped by task — so everything you need for, say, network recon or log analysis sits together in one place.

| 8 | Package Management |
| 9 | Text Processing & Searching |
| 10 | Archiving, Compression & Transfer |
| 11 | Hashing, Checksums & Verification |

Each entry lists the command and a short, clear meaning — no fluff, no assumed prior knowledge.

## ⚠️ Responsible Use

The network recon and security tools listed (`nmap`, `hydra`, `hashcat`, etc.) are standard, legitimate parts of a security professional's toolkit. They are documented here for reference only — use them exclusively on systems you own or are explicitly authorised to test.
